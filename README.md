# 狄公案牍

钱雁秋版《神探狄仁杰》四部十案观剧资料站。包含 188 个独立人物档案及原剧相关画面，支持按案件浏览人物、检索与阅卷簿。人物介绍正文不少于 100 字，关键身份、阵营与结局默认折叠。尚未找到可靠角色照的条目保留空位；无法追溯原图的旧图已撤下，缺图原因记录于 `content/CONTENT-REVIEW.md`。页脚包含艾影流浪署名和自愿赞赏码。

在线访问：https://digong.aiyingliulang.qd.je/

打开 `index.html` 预览。剧集入口与图片来源见各条目。本站为非官方作品，电视剧与图片权利属于原权利人。

实际页面数据为 `v2/archive-data.js`，界面为 `v2/edition.js`；根目录 `data.js` 是旧版数据，当前两个入口均不再加载。人物图片的历史补丁已合并进实际数据，避免覆盖新的校勘结果。

本地运行：`python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/`；`/v2/` 入口同样可用。

内容检查：`node checks/content.cjs`；浏览器检查见 `checks/browser.cjs` 文件头说明。

人物校勘的范围、来源差异和图片待确认情况见 [内容校勘记录](content/CONTENT-REVIEW.md)，逐人参考链接见 [人物校勘清单](content/cast-review.json)。具名但出场细节不足的条目保留说明，不把演员表等同于逐集出场证据。
